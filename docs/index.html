🔥 热点追踪 Hotspot Tracker

AI 驱动的全球科技热点追踪工具，专为腾讯云国际站内容团队打造。自动采集 7 大平台热点， 深度分析关联性，生成可直接使用的写作素材。

✨ 核心功能

  • 7 大数据源自动采集 — HackerNews / GitHub Trending / ProductHunt / HuggingFace / V2EX / 36氪 / AI Newsletter
  • 深度内容抓取 — GitHub README 全文 / 社区帖子全文 / 项目详情
  • 智能分析标注 — AI相关判断 / 云行业识别 / 腾讯云产品关联 / 竞品分析
  • 自动翻译 — Google Translate 英文摘要→中文
  • 腾讯文档同步 — 一键写入多维表格（全量热点 + 精选话题）
  • 写作包生成 — Markdown 格式，可直接用于内容创作
  • 开发者信息增强 — GitHub API + 主页爬取获取公开邮箱
  • 纯静态部署 — GitHub Pages 零成本托管，任何人可直接访问

🛠 技术栈

🐍 Python 3 🔍 BeautifulSoup4 🌐 Requests 🌍 Google Translate 📊 企业微信 Webhook 📄 CSV / JSON / Markdown 🎨 原生 HTML/CSS/JS 🚀 GitHub Pages

📂 项目结构

热点追踪/ ├── index.html ← 前端界面（纯静态，可部署） ├── docs/ ← GitHub Pages 部署目录 │ ├── index.html ← 部署的前端页面 │ └── data/ ← 预生成的 JSON 数据 │ ├── index.json ← 日期索引 │ └── 2026-03-22.json ← 每日数据 ├── generate_static.py ← 静态站点数据生成器 ├── web_app.py ← 本地 Web UI 后端 (Flask) ├── web_ui.html ← 本地 Web UI 前端 ├── run.sh ← 命令行一键运行 ├── setup.sh ← 首次安装 ├── requirements.txt ← 依赖清单 ├── merge_master_table.py ← 历史总表合并 ├── sync_to_wecom_sheet.py ← 腾讯文档同步 ├── scripts/ ← 核心采集脚本 │ ├── daily_hotspot_agent.py ← 主流程调度 │ ├── fetch_news.py ← 7 大数据源爬虫 │ ├── content_analyzer.py ← 内容分析引擎 │ ├── rss_parser.py ← RSS 解析器 │ └── wecom_doc_writer.py ← 企业微信文档写入 └── output/ ← 数据输出目录

🚀 部署方式

# 1. 本地运行采集 ./run.sh # 2. 生成静态站点数据 python3 generate_static.py # 3. 推送到 GitHub（自动部署到 GitHub Pages） git add docs/ git commit -m "update hotspot data" git push # GitHub Pages 设置： # Settings → Pages → Source: Deploy from branch # Branch: main, Folder: /docs
