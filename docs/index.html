🔥 热点追踪 Hotspot Tracker

热点追踪是腾讯云国际站内容团队的 AI 驱动工具，
帮助团队每天自动发现全球科技热点、识别与腾讯云产品的结合点、快速输出内容草稿，
实现从"热点发现 → 产品关联 → 内容生产 → 社媒互动"的全链路闭环。

🎯 我们在解决什么问题？

腾讯云国际站需要持续产出有热点锚点的技术内容来推广产品（Lighthouse、EdgeOne、Hunyuan、CodeBuddy 等），
但人工追踪热点→判断相关性→写作→社媒互动的链路很长、很慢。

热点追踪系统做了什么：

  • 🤖 自动采集 — 每天从 9 大平台采集 50-80 条科技热点
  • 🧠 智能分析 — 自动判断 AI 相关性、云行业关联、腾讯云产品匹配度
  • 📝 内容生产 — 为每个关联产品生成 P0/P1 优先级的 Draft 草稿
  • 🐦 社媒互动 — 找到 Twitter/Reddit 上的真实讨论帖，提供可直接互动的链接
  • 🤝 KOC 发现 — 自动从热点中发现潜在合作者（GitHub 开发者、社媒讨论者）

📡 9 大数据源

🦄 HackerNews — 硅谷热点 🐙 GitHub Trending — 开源趋势 🐱 ProductHunt — 新产品 🤗 HuggingFace — AI论文 🤓 V2EX — 极客社区 🚀 36氪 — 创投快讯 🧠 AI Newsletter — AI内参 🌐 全网搜索 — 竞品/行业 🐦 Twitter/Reddit — 社媒讨论

📊 核心 Tab 功能说明

📊 数据看板

当天采集概览：总量、AI/云占比、高分热点、P0/P1数量、来源/技术标签分布

📋 全量数据

所有采集到的热点完整列表，支持搜索/来源/优先级/产品/评分多维筛选，可切换历史全量模式

⭐ 精选话题

P0/P1 优先级 + 腾讯云高关联度的精选内容，附带产品结合点和写作角度建议

📝 每日总结

当日热点趋势的结构化总结，快速了解今天发生了什么

🎯 内容行动中心

三合一行动面板：深度写作包 + 分产品AI Draft(P0/P1) + 社媒互动推荐（含原帖链接）

🤝 KOC 建联库

从热点中自动提取的潜在合作者库，支持搜索/来源/评分筛选，历史跨天积累

🛠 技术栈

🐍 Python 3 🔍 BeautifulSoup4 🌐 Requests + DuckDuckGo 🌍 Google Translate 📊 企业微信 Webhook 📄 CSV / JSON / Markdown 🎨 原生 HTML/CSS/JS（无框架） 🚀 GitHub Pages 静态部署

🚀 运行方式

# 1. 采集 + 分析 + 生成（一键） cd scripts && python3 daily_hotspot_agent.py --output-dir ../output # 2. 生成静态站点数据 cd .. && python3 generate_static.py # 3. 推送到 GitHub Pages 自动部署 git add docs/ && git commit -m "update data" && git push

📈 数据特点

  • 全量积累 — 不只是当天数据，全量数据/精选话题/KOC建联库都跨天积累
  • 纯本地规则 — 分析引擎不依赖 LLM API，纯规则匹配+评分，速度快、成本零
  • 零 API Key — 所有数据源均无需付费 API Key（DuckDuckGo / GitHub 公开 API）
  • 可扩展 — 新增数据源只需写一个 fetch 函数 + 注册到 SOURCE_SPECS
