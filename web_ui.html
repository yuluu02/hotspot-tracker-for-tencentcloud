🔥 热点追踪 Hotspot Tracker

AI 驱动的全球科技热点追踪工具，专为腾讯云国际站内容团队打造。自动采集 7 大平台热点， 深度分析关联性，生成可直接使用的写作素材。

✨ 核心功能

  • 7 大数据源自动采集 — HackerNews / GitHub Trending / ProductHunt / HuggingFace / V2EX / 36氪 / AI Newsletter
  • 深度内容抓取 — GitHub README 全文 / 社区帖子全文 / 项目详情
  • 智能分析标注 — AI相关判断 / 云行业识别 / 腾讯云产品关联 / 竞品分析
  • 自动翻译 — Google Translate 英文摘要→中文
  • 腾讯文档同步 — 一键写入多维表格（全量热点 + 精选话题）
  • 写作包生成 — Markdown 格式，可直接用于内容创作
  • 开发者信息增强 — GitHub API + 主页爬取获取公开邮箱

🛠 技术栈

🐍 Python 3 🌶 Flask 🔍 BeautifulSoup4 🌐 Requests 🌍 Google Translate 📊 企业微信 Webhook 📄 CSV / JSON / Markdown 🎨 原生 HTML/CSS/JS

📂 项目结构

热点追踪/ ├── web_app.py ← Web UI 后端 (Flask) ├── web_ui.html ← 前端界面 ├── run.sh ← 命令行一键运行 ├── setup.sh ← 首次安装 ├── requirements.txt ← 依赖清单 ├── merge_master_table.py ← 历史总表合并 ├── sync_to_wecom_sheet.py ← 腾讯文档同步 + 每日总结 ├── scripts/ ← 核心采集脚本 │ ├── daily_hotspot_agent.py ← 主流程调度 │ ├── fetch_news.py ← 7 大数据源爬虫 │ ├── content_analyzer.py ← 内容分析引擎 │ ├── rss_parser.py ← RSS 解析器 │ └── wecom_doc_writer.py ← 企业微信文档写入 └── output/ ← 输出目录
