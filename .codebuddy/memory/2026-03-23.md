## V20 修复 — KOC 邮箱显示 + Reddit RSS

### KOC 邮箱显示修复 (`index.html`)
- **问题**: `renderKocCards()` 中邮箱只显示 📧 图标，未显示实际邮箱地址
- **原因**: 第 1264 行 `contactChips += '<span class="koc-tag">📧</span>'` 没有把 email 地址渲染出来
- **修复**: 改为 `<a href="mailto:${email}" class="koc-tag">📧 ${email}</a>`，可点击发送邮件
- social_links 也增强显示：从 URL 提取域名显示（如 youtube、linkedin）
- 联系方式列最大宽度 260px + white-space:normal 以容纳完整邮箱

### Reddit 403 修复 (`fetch_news.py`)
- Reddit JSON API（含 old.reddit.com）全部返回 403
- 改用 **Reddit RSS/Atom feed**：`https://www.reddit.com/r/{sub}/{sort}/.rss`
- 新增 `_fetch_reddit_rss()` 函数，解析 Atom XML
- `_fetch_reddit_search()` 改为 RSS + 本地关键词匹配
- 时间解析用 `datetime.fromisoformat()` 替代 dateutil（无需额外依赖）
- 测试确认：获取到 7 条实时 Reddit 帖子（35分钟前~11小时前）
